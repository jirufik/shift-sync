# secrets/

Сюда кладётся **`service-account.json`** — ключ сервисного аккаунта Google,
скачанный из Google Cloud Console.

Как его получить и как ограничить доступ одним календарём — `docs/SETUP.md`, раздел 4.

Каталог в `.gitignore`: ключ не должен попасть в репозиторий. Он даёт право
писать события в календарь, который на него открыт, поэтому обращаться с ним
надо как с паролем.

Проверить, что ключ работает и что лишнего доступа нет:

```bash
pnpm --filter @fc/api run check:google
```
