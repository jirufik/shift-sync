# Shift Sync — заметки для работы с проектом

Репозиторий публичный. Настоящий график (скриншоты, PDF, их OCR, эталоны), старые снимки
интерфейса и личные документы лежат в `private/` — в `.gitignore`, в коммит не попадают.
Подробно — `docs/DECISIONS.md`, D-033.

## Перед коммитом

- Хук включается один раз на клон: `git config core.hooksPath .githooks`. Он запускает
  `node scripts/scan-secrets.mjs --staged`; сам сканер проверяется `pnpm scan:test`.
- Свои опознаватели (имена, работодатель, ID календаря и сервисного аккаунта) — в
  `.scan-local.json` (игнорируется). Короткие слова, встречающиеся внутри обычных, туда не класть.
- Картинки и PDF сканер не читает — новые кадры смотреть глазами.

## Образцы и тесты

- Все образцы в `samples/` — выдуманные, генерируются из `tools/samples/schedule.mjs`
  (`pnpm samples`). После правки генератора кадров: `tools/ocr-bench` → `node run.mjs` →
  `node score.mjs` → скопировать `raw-v5-salvage.json` в `apps/api/test/fixtures/ess-synthetic.json`.
- Тест `apps/api/test/private-samples.spec.ts` работает только при наличии `private/samples/`.

## Скриншоты для README

- Только с отдельной пустой базы (`fc_shots`) и без Google: порядок — в шапке
  `apps/web/scripts/screenshots.mjs`. Скрипт сам откажется, если в базе есть данные.
- Запускать собранное приложение (`node dist/main.js` в `apps/api`), не `pnpm run dev`:
  turbo теряет необъявленные переменные, и `DB_NAME` уходит в рабочую базу.
- Перед съёмкой проверить, куда подключился сервис: `pg_stat_activity` и
  `tr '\0' '\n' < /proc/<pid>/environ | grep DB_`. Останавливать по PID из
  `ss -lptn 'sport = :<порт>'`, не `pkill -f`.
- Посмотреть каждый кадр: нет ли реального и нет ли кириллицы на английском экране.

## Локальное

- `docker-compose.override.yml` (игнорируется) добавляет контейнеру сеть туннеля. Без него
  рабочий экземпляр после пересборки потеряет доступ снаружи.
